# Panda Rider - Huawei Production Build Configuration

Complete guide for building and submitting Panda Rider apps to Huawei App Gallery.

## Prerequisites

### System Requirements
- Windows, macOS, or Linux
- Android SDK 21+
- Flutter 3.10+
- Java Development Kit (JDK) 11+
- 30GB free disk space

### Required Accounts & Setup
1. **Huawei AppGallery Connect** account (free)
   - Register at https://appgallery.cloud.huawei.com
   - Create Huawei ID with 2FA

2. **Huawei Mobile Services (HMS)**
   - Register HMS project
   - Enable required APIs:
     - Push Kit (notifications)
     - Location Kit (GPS)
     - Wireless Mobile Connectivity Kit (network)
     - Account Kit (authentication)

3. **App Signing Certificate**
   - SHA-256 fingerprint (generated by script)
   - SHA-1 fingerprint (for older APIs)

## Installation Steps

### 1. Install Huawei Development Tools
```bash
# Download Huawei HMS Core library
flutter pub add huawei_push
flutter pub add huawei_location
flutter pub add huawei_account
flutter pub add huawei_core

# Android SDK setup
# Use Android Studio or command line:
sdkmanager --install "build-tools;31.0.0"
sdkmanager --install "platforms;android-31"
```

### 2. Huawei AppGallery Connect Setup

#### Create App Entry
1. Log in to [AppGallery Connect](https://appgallery.cloud.huawei.com)
2. My Apps > Create > New App
3. App info:
   - App name: Panda Rider (or Panda Rider Driver)
   - Platform: Android
   - Category: Travel
   - Language: English (or local)

#### Configure App
1. Go to App Information
2. Set up:
   - App icon (512x512 PNG)
   - Category: Travel/Transport
   - Permissions needed
   - Content rating

#### Get Signing Certificate Info
1. Generate keystore (if not exists):
```bash
keytool -genkey -v \
  -keystore ~/.android/panda-rider.keystore \
  -keyalg RSA -keysize 2048 -validity 10000 \
  -alias panda-rider \
  -storetype PKCS12
```

2. Get SHA-256:
```bash
keytool -list -v \
  -keystore ~/.android/panda-rider.keystore \
  -alias panda-rider
```

3. Register certificate in AppGallery Connect:
   - App > App Information > Certificate Fingerprint
   - Add SHA-256 and SHA-1

### 3. HMS Project Configuration

#### Enable Push Kit
1. My Projects > Select project
2. Manage APIs
3. Enable: Push Kit, Location Kit
4. Download config file: `agconnect-services.json`
5. Place in: `panda-rider/flutter-customer/android/app/`

#### Create Release Key
1. App > Package Management
2. Request release certificate
3. Download certificate

## Upload to App Gallery

### Method 1: AppGallery Connect Web Portal (Recommended)
1. Sign in to AppGallery Connect
2. My Apps > Select app
3. Package Management
4. Upload release package:
   - Select: Version type (Release)
   - Upload APK
   - Wait for upload completion
5. App Information:
   - Add descriptions
   - Upload screenshots
   - Set content rating
6. Review and Submit

### Method 2: Command Line (Advanced)
```bash
# Using hms-cli-plugin
npm install -g hms-cli-plugin

# Login
hms-cli app login

# Upload
hms-cli app upload \
  --app-id com.pandarider.customer.huawei \
  --apk-path builds/huawei/panda-rider-customer-huawei-1.0.0.apk
```

## Troubleshooting

### Common Issues

#### APK Upload Fails
```bash
# Verify APK integrity
jarsigner -verify -certs -verbose \
  builds/huawei/panda-rider-customer-huawei-1.0.0.apk

# Check APK size (max 100MB for App Gallery)
ls -lh builds/huawei/panda-rider-customer-huawei-1.0.0.apk
```

#### "Certificate mismatch" Error
1. Regenerate certificate SHA-256:
```bash
keytool -list -v -keystore ~/.android/panda-rider.keystore
```
2. Update in AppGallery Connect
3. Rebuild APK

#### HMS Core Library Issues
```bash
# Update HMS dependencies
flutter pub upgrade huawei_push
flutter pub upgrade huawei_location

# Clean and rebuild
flutter clean
flutter pub get
flutter build apk --release
```

#### App Rejected
- Review rejection reason in AppGallery Connect
- Common reasons:
  - Privacy policy missing/invalid
  - App crashes on test device
  - Prohibited content detected
  - Payment currency not matching region
- Make corrections and resubmit
